# Learning Science (education mode)

Evidence-based moves that make a deck *teach*, not just *tell*. Each maps to a `narrativeRole` or archetype so
it shows up in the storyboard.

## Retrieval practice (testing effect)
Recalling information strengthens memory far more than re-reading it. After each concept, add a `retrieval`
slide that asks learners to *produce* the answer (not recognise it).
- Prompt with questions, not summaries: "What would happen if…?", "Trace this by hand."
- One retrieval slide per concept minimum; the QA gate requires at least one per deck.

## Spacing & interleaving
- **Spacing:** revisit earlier concepts later in the deck (a `summary`/`recap` that pulls a prior concept
  back). Don't teach a concept once and abandon it.
- **Interleaving:** when concepts are related, alternate and contrast them (`comparison`) rather than blocking
  all of concept A then all of B.

## Worked examples + faded guidance
For `apply`-level objectives, **model a full worked example first** (`worked-example` archetype, numbered
steps), then have learners attempt a similar one (`retrieval`). Gradually remove scaffolding across examples
("faded worked examples"). This manages cognitive load for novices.

## Cognitive load management
- **One message per slide.** Split anything with two ideas.
- **Avoid redundancy:** don't put the same text in the bullet *and* read it verbatim; let the visual carry
  some of it (notes hold the script).
- **Signal structure:** kickers + section dividers tell learners where they are.
- Prefer a labelled diagram/chart over a paragraph (multimedia principle), but keep it clean (coherence
  principle — remove decorative clutter that doesn't teach).

## Dual coding
Pair words with a relevant visual (`data`, diagram image) so the idea is encoded two ways. The six style
systems are designed to keep visuals purposeful, not decorative.

## What to avoid
- Learning styles / VAK matching — no reliable evidence; don't design around it.
- Wall-of-text slides — they defeat every principle above.
- "Fun" animation for its own sake (and in any case SlideSage is static by design).

Each beat you add should trace back to an objective. If a slide doesn't advance an objective or check one,
cut it.
